# Combinatorics

This repository currently consists of the [`content`](content/) directory: a collection of largely self-contained notes on combinatorics, together with conjectures, proofs and proof outlines, computational evidence, computer-assisted proof material, reference implementations, optimized programs, examples, and related research summaries. Each topic has its own documentation; begin with [`content/README.md`](content/README.md) and then the relevant `explanation.tex`.

## About CRAIG

This repository provides the base mathematical material for the current [CRAIG repository](https://github.com/grhmhwks/Craig) on GitHub.

CRAIG, the **Combinatorial Research Assistance Interactive Guide**, is an open-source application being developed to help readers search, understand, and computationally explore research material. It is intended to provide repository-grounded explanations, guide readers to relevant sources, and make connections among different combinatorial topics easier to investigate.

The material can be read directly here, but once CRAIG is complete, using CRAIG will provide the best experience for exploring it.
